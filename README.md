​
<p align="center">Give it a file size limit and it'll try to squeeze your image under it. It tries to keep the highest quality possible while staying under the limit, and if lowering the quality isn't enough, it'll shrink the image dimensions too. Supports JPEG, PNG, and WebP, with an Auto format option, as well as an optional maximum width.</p><br>
